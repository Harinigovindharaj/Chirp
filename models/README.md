# models/

Place your trained model file here:

    abusive_classifier.pkl

## How to generate it
1. Open `abusive_language_classifier.ipynb` in Google Colab
2. Upload `Suspicious_Communication_on_Social_Platforms.csv` when prompted
3. Run all cells — the notebook will auto-download `abusive_classifier.pkl`
4. Move the downloaded file into this directory

## Path expected by the app
    chirp/models/abusive_classifier.pkl
